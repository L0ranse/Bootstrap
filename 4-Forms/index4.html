Range (Slider)

In Bootstrap, the .form-range class styles the <input type="range"> element in HTML.

Note: min sets the starting value, max sets the highest value, step sets the increment, and value sets the initial value.

1. Basic usage

0 (Muted) 100 (Highest)

2. Different range and step value

Values range from -10 to 40 and increase by 5.

3. Disabled range

Features used

  • type="range": Creates a slider control.
  • class="form-range": Applies the Bootstrap style.
  • disabled: Prevents the control from being changed.
  • <output>: Displays the selected value.
